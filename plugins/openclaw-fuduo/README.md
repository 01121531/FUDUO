# 富多 OpenClaw 工具插件

该插件向 OpenClaw 注册 11 个只读经营工具。模型只能提交店铺 ID、日期范围和数量限制，不能提交 URL、Header、Cookie、SQL 或 Authorization。

## 构建和安装

```bash
pnpm --filter @fuduo/openclaw-fuduo build
openclaw plugins install ./plugins/openclaw-fuduo
openclaw plugins inspect fuduo-business --runtime --json
```

在 OpenClaw 配置中为插件设置：

```json
{
  "apiBaseUrl": "http://api:3001/api",
  "serviceToken": "与 INTERNAL_SERVICE_TOKEN 相同的至少 32 字符随机值"
}
```

生产环境应把 `serviceToken` 配置为环境 SecretRef，而不是写入明文：

```json
{
  "apiBaseUrl": "http://api:3001/api",
  "serviceToken": {
    "source": "env",
    "provider": "default",
    "id": "FUDUO_INTERNAL_SERVICE_TOKEN"
  }
}
```

微信渠道使用 `@tencent-weixin/openclaw-weixin`，只开启私聊，并通过 OpenClaw pairing 批准内部员工账号。

生产启动脚本还会把 OpenClaw 的模型固定为 `fuduo-runtime/default`。该别名请求 API 内部模型代理，由 API 在每次请求时读取后台的“默认对话模型”和“备用模型”配置；模型供应商 API Key 不写入 OpenClaw 配置或共享卷。
